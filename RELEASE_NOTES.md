# INQ Multik 0.1.0

Перший реліз для World of Tanks 2.4.1.1: EU / NA / ASIA у штатному списку серверів одного клієнта.

- Один файл ігрової логіки в одному .wotmod; без ядра RaJCeL, BAT, runtime-конфігів і підміни scripts_config.xml.
- Штатні меню, реєстр серверів і пінгер.
- Корекція регіонального префікса версії зі збереженням оригінальної перевірки числової версії, патча та контенту.
- «Авто» в межах вибраного регіону та захист від використання звичайного збереженого token2 іншого регіону.
- Перевірка очікуваних інтерфейсів при запуску і відкат власних змін при помилці.
- Упорядковано внутрішні константи й документацію. Поведінка входу з перевіреної test1 збережена.
- Версія ігрового скрипта при збірці синхронізується з meta.xml, зокрема для ручних випусків.

## Перевірено

- Автоматичні контрактні перевірки з макетами API WoT.
- Компіляція Python 2.7, поведінка перехоплень у Python 2.7 і склад пакета.
- У клієнті користувача: ASIA → NA без перезапуску, завантаження бойових сцен на NA та повернення в ангар.
- Вхід на EU підтверджений після нового запуску.

## Межі перевірки

Повний цикл NA → EU без перезапуску у наданому журналі не підтверджено; під час повторних підключень були мережеві повідомлення та відключення, причина яких не встановлена. У логу немає Python traceback або помилки сумісності версії Multik.

WGC/Steam і вебавторизація для чужого регіону залишаються штатними й не заявляються повністю перевіреними. Пакет не додає відсутніх регіональних моделей або стилів. Поточний ASIA-конфіг містить ASIA1; старі окремі записи Hong Kong/Australia не додаються.

## Встановлення

Прибрати попередню версію Multik та конфліктуючий RaJCeL RegionChanger. ZIP розпакувати в папку гри; .wotmod має опинитися в mods/2.4.1.1/. Якщо використовується окрема XML-підміна RaJCeL тільки для зміни регіонів, її також потрібно прибрати.

Після оновлення WoT перевірити активну папку mods у paths.xml. Якщо внутрішні інтерфейси гри не змінилися, сам код може не потребувати правок; сумісність із кожним майбутнім патчем наперед не гарантується.
